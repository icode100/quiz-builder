GATE CSE 2012 - Question Booklet Code A
65 single-choice MCQs, 100 marks. Printed order: CS 1-55, then GA 56-65.
The supplied key's Code A column matches this paper; other columns do not.

Run ../start-quiz.cmd on Windows or ../start-quiz.command on macOS, then open:
http://127.0.0.1:8765/gate-cse-2012/
Node.js is required; no packages, build step, account or internet is needed.
Keep the same browser/profile and HTTP origin for automatic draft recovery.

CS 1-25 and GA 56-60 carry 1 mark; the remaining questions carry 2 marks.
Wrong ordinary answers deduct exactly -1/3 or -2/3. Unanswered ordinary
questions receive zero. Linked second questions CS-53 and CS-55 have no
deduction and are evaluated only if CS-52 and CS-54 respectively are correct.
Otherwise an answered dependent is Not evaluated and receives zero marks.
Common-data pairs CS-48/49 and CS-50/51 have no grading dependency.

Marks to All: CS-3, CS-29, CS-38, CS-39, CS-45 and GA-60. These six questions
award 10 marks even unanswered. Blank: 10/100; perfect: 100/100, comprising
59 correct questions and six awards; all wrong: -56/3 out of 100.

Practice displays one question at a time. MCQ choices save before advancing;
Previous, Next, Skip and the question map navigate without clearing work.
Home returns to the quiz list. Mark for review flags are independent of answers.
The timer offers 180, 150, 120, 90, 60 or 30 minutes and never auto-submits.
Submit resets and pauses it. A running timer counts time while the page closes.
The shared Calculator opens from its floating button. Light/dark mode is
remembered; dark mode inverts question images through CSS, preserving PNGs.

Unfinished responses, flags and timer cache automatically in this browser.
Submit shows all answers, outcomes and marks, with Save report and Print report.
A successful server save writes the latest attempt.json and clears the draft;
a failed save keeps the draft and report. Report stars retain submitted flags.
Review last attempt recomputes the saved report without replacing the current
draft; Back to quiz restores the prior view. Attempt again starts fresh practice
without changing the saved submission. Clearing browser data or ending a
private session can erase unfinished work; drafts do not transfer to another PC.
