GATE CSE 2017 - Set 2 (11 February 2017, session 2)

Open http://127.0.0.1:8765/gate-cse-2017-set-2/ after starting the server
with start-quiz.command on macOS or start-quiz.cmd on Windows in the parent folder.
Node.js is required; no packages, build step, account or internet connection is needed.

65 questions, 100 marks: CS 1-55, then GA 56-65; 45 MCQ and 20 NAT.
CS 1-25 and GA 56-60 carry one mark; the remaining questions carry two.
Wrong MCQs deduct exactly one-third of their marks; NAT has no deduction.
The paper's rounded -0.33/-0.66 labels are superseded by the exact rule in
the GATE 2017 Information Brochure, sections 5.4 and 5.4.6.
CS-21 accepts -0.01 through 0.01 inclusive; CS-45 accepts exactly 4.72.
No alternative MCQ keys, MSQ, marks-to-all awards or linked dependencies.

Use Previous/Next or the question map. Responses, flags, syllabus exclusions,
timer and last practice question are cached in this browser. Submit grades
and saves the latest report; Review last attempt becomes available after
a nonblank saved submission. Rough work is stored separately per question.
Keep using the same browser/profile and http://127.0.0.1:8765 origin.
On phones, scroll within each question image sideways to read its full width.

Original supplied sources remain unchanged in Downloads, outside this quiz:
GATE2017-Set-2_compressed.pdf (25 pages, question paper)
GATE2017-Set-2.pdf (2 pages, answer key)
Their SHA-256 hashes, key entries and crop provenance are in quiz-data.js.
All 65 question crops are lossless 240 DPI source pixels; source raster
softness, colors, diagrams and watermarks are preserved. Light mode and print
use original colors; dark mode inverts them only on screen.

Verification: node tests/quiz-2017-set-2.test.cjs from the parent folder.
Independent keys, every MCQ choice, numerical endpoints/outside values,
blank/perfect/mixed/negative scores, assets, drafts and saved-review behavior
are tested with simulated storage and disposable server folders.
No real attempt.json is created or reset during development.
