GATE CSE 2019: 65 questions, 100 marks; 41 MCQ and 24 NAT.
Launch ..\start-quiz.cmd (Windows) or ..\start-quiz.command (macOS), then open http://127.0.0.1:8765/gate-cse-2019/index.html in the same browser/profile each time. Node.js is required; no internet or npm packages are needed. Opening index.html directly is not the supported storage flow.
Unfinished responses and Mark for review flags cache automatically in the browser. Clearing browser data or ending a private session can erase them. If caching fails, keep the tab open.
Submit shows each question's response, outcome, correct answer, and marks, and saves the latest attempt.json. The draft and flags clear only after a successful save. Invalid nonblank numerical input blocks Submit; a failed save retains the draft and report.
Review last attempt starts disabled and becomes available only when a readable saved file contains a non-null answer. Review regrades the verified responses without replacing the draft; Back to quiz restores the prior view. Attempt again starts fresh practice and preserves the saved submission. Save report and Print report remain available.
Clear response preserves its review flag. Clear answers and fresh Attempt again clear all flags. Flags never affect scores or enter attempt.json. The question map supports jumps in practice and reports; theme is remembered separately.
MCQ wrong answers deduct one-third of their marks; NAT has no negative marking. Unanswered questions score zero. CS-12 accepts C OR D as a single-choice response; CS-22 accepts 0.502-0.504 inclusive; CS-42 accepts 3.7-3.8 OR 4.0-4.1 inclusive, with the gap excluded. Blank: 0/100; perfect: 100/100; no marks-to-all entries.
Unchanged source copies: 2019_CS_Paper1.pdf (16 physical pages) and 2019-Keys1.pdf (3 pages). GA 1-10 and CS 1-55 keep separate numbering. The printed headers say GA Set-6 and CS Set-2 despite the Paper1 filename; no session number is inferred. The CS footer denominator says 15, while the supplied file contains 13 CS pages and all 55 CS questions.
Includes 65 original question PNG crops at 240 DPI with full-resolution links, source pages, and recorded PDF-point crop rectangles. Every source page and crop was visually checked against the supplied paper.
Marking reference: GATE 2019 Information Brochure section 5.2.1, https://gate.iitm.ac.in/gate2019/pdfs/GATE_2019_Information_Brochure.pdf (official search index verified; direct URL currently returns 404). Official archive: https://gate.iitb.ac.in/G21/prev_qp.php.
Home: Attempted before means at least one non-null saved answer. Unsolved only filters the list. Reset saved attempts removes submitted reports after confirmation; unfinished browser drafts and theme remain intact.
Verification: node tests\quiz-2019.test.cjs uses a separately transcribed key and simulated storage/server. It never submits to the user's real quiz.

Timer: choose 180, 150, 120, 90, 60, or 30 minutes (default 180), then Start, Pause, or Reset. No custom duration is available. Changing the preset or Reset leaves it paused. It restores with the browser draft; a running timer counts elapsed time while closed. At zero it stops with a message and you can keep answering. Submit resets it even for invalid input or a failed save; Clear answers preserves it. Reviewing hides the timer while a running timer keeps counting; Back to quiz shows it again. It never enters attempt.json and is hidden in reports and print.

Theme: remembered blue accents in light/dark mode; the dark page remains pitch black and the light page keeps its existing background.
