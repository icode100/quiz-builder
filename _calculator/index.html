Syntax & keyboard help

Type or use the keys. Press Enter or = to calculate; Esc closes the panel. Select text to wrap it in a function.

Examples: sin(30), 2^10, ncr(5,2), root(27,3), 1e-3. Use * for multiplication and % for remainder; percentage is /100. More shows hyperbolic functions, absolute value, floor, ceil and roots.

Trigonometric inputs and inverse outputs use DEG or RAD. log is base 10; ln is base e. Factorials and combinations require nonnegative integers. Memory and Ans last while this page is open. Results use JavaScript floating-point arithmetic and may include rounding error. This is a practice tool.
