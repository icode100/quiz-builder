GATE CSE 2015 - Set 1, 7 February forenoon (Shift 1)
65 questions, 100 marks: 45 MCQ and 20 NAT.

Start ../start-quiz.cmd (Windows) or ../start-quiz.command (macOS), then open:
http://127.0.0.1:8765/gate-cse-2015-set-1/
Node.js is required; no npm packages or internet connection are needed.

The primary source is 2015CS_S05_compressed.pdf, containing questions and key.
Its original order/numbering is retained: GA 1-10, then CS 11-65. The separate
GATE2015-Set-1.pdf contains the same questions in a different order, so it must
not receive this key by position. Cross-reference mapping, original filenames,
SHA-256 hashes, page sizes and crop rectangles are recorded in quiz-data.js.
Both original PDFs remain unchanged in Downloads; no copies are stored here.

All question images retain original mathematics, diagrams, tables, code and
options. Coloured answer lists and PDF annotations are excluded. Crops use
240 DPI; source raster softness remains. Light mode/print use original colours,
and dark mode inverts their appearance with CSS. All 24 primary pages,
21 reference pages and 65 final crops were visually inspected.

GA 1-5 and CS 11-35 carry one mark; GA 6-10 and CS 36-65 carry two.
Wrong MCQ answers deduct exactly one-third of the question marks. NAT has no
negative marking. Unanswered questions score zero. CS-39 accepts 0.40-0.46
inclusive; other numerical answers are exact, including CS-34=-5 and CS-58=-1.
Blank: 0/100; perfect: 100/100; all wrong: -64/3 out of 100.
Scoring provenance is recorded in data and the independent test fixture.

Practice uses the carousel, Previous/Skip/Next, unchanged numbered map,
Clear response, Mark for review, Home, timer and shared Calculator.
Answers, review marks and timer cache in the same browser/profile and origin.
Submit shows the full report, saves the latest attempt.json and clears the
draft only after a successful save. Review last attempt preserves a new draft;
Back to quiz restores it. Attempt again never overwrites a saved submission.
Save report and Print report remain available.

Verification: node tests/quiz-2015-set-1.test.cjs
Tests use simulated drafts and disposable server folders, never real attempts.
