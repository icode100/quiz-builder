GATE CSE 2025 - Set 1 (CS1, session 1)

Run start-quiz.command on macOS or start-quiz.cmd on Windows from the workspace.
Open http://127.0.0.1:8765/gate-cse-2025-set-1/ in the same browser/profile.
On macOS the launcher defaults to no browser; --with-browser opens the quiz list.

65 questions, 100 marks: 30 MCQ, 13 MSQ, 22 NAT.
Preserves continuous printed numbering: GA 1-10, then CS 11-65.
MCQ wrong answers lose exactly one-third of the question marks. MSQ requires
the exact answer set, with no partial credit. MSQ/NAT have no negative marking.
Unanswered questions receive zero. Blank: 0/100; perfect: 100/100; all wrong: -15/100.
Official marking reference: https://gate2025.iitr.ac.in/question-paper-pattern.html
Answer rules: https://gate2025.iitr.ac.in/question-papers.html

Uses the supplied CS1/session-1 key. CS 28, 49 and 50 remain MSQ even though each
has one correct option. Numerical ranges are inclusive, including CS 31's
negative interval, CS 60 (7-8), and CS 65 (10-11), exactly as supplied.

The quiz contains 66 lossless 240 DPI original question crops, preserving the
source diagrams, equations, tables, code, options and watermark. CS 11 has two
ordered parts from pages 10-11. CS 64 and 65 use separate crops from page 64.
quiz-data.js records filenames, hashes, source pages, PDF rectangles and pixel
geometry. No source PDFs are duplicated here. Every page/key/crop was visually
checked; every PNG matches a fresh source rectangle pixel-for-pixel.

The template supplies the carousel, question map, review flags, six-preset timer,
automatic browser drafts, theme, Submit report, Save/Print and saved Review.
The server supplies the shared calculator. Full-resolution image links and print
use original colours; dark mode inverts images through CSS only.

Unfinished responses and timer state belong to this browser/profile. Submit
saves the latest attempt.json only after a valid submission; draft cache clears
only after a successful server write. Review/Retry do not change the saved file.
No attempt.json is created during construction or verification.

Checks: node tests/quiz-2025-set-1.test.cjs
Tests use simulated browser state and disposable server folders.
Current practice scoring: Out of syllabus beside Clear response and Mark for review manually excludes a question from earned and maximum marks, including marks-to-all awards. Responses and review flags remain. If a linked prerequisite is excluded, its included dependent is graded independently with the original penalty. Percentage takes priority in reports, Save/Print, and home cards/bars; earned/eligible marks remain visible. Original weights and negative penalties apply. If all questions are excluded, percentage is unavailable with 0/0 marks. Paper totals and score examples above assume no exclusions.

Exclusions restore with the browser draft and are saved with Submit. Clear response keeps them; Clear answers and fresh Attempt again clear them. A successful save clears practice exclusions/draft while keeping the report snapshot; invalid input or a failed save preserves them. Saved Review uses its saved exclusions; Back to quiz restores practice. Older submissions without exclusions include every question.

Practice navigation also caches the last viewed question, including MCQ auto-advance and map jumps. Refresh/reopen resumes there, even without answers; older drafts start at the first question. Report navigation never changes it. Clear answers and fresh Attempt again return to the first question.

Rough work: click the pen icon for a per-question drawing notebook with Pen, Highlighter, Eraser, colors, widths, Undo/Redo, and undoable Clear page. Blank, Dotted, Ruled or Grid paper is remembered per question; Clear page keeps the paper style. Completed strokes save in this browser separately from answers and scoring and restore after reopening; Submit, Clear answers, Attempt again and Review do not remove notes. Question map, the pen button, or Escape from the panel closes it; small screens show it below the test. New pages start Dotted. Paper and ink follow the current light/dark theme; existing drawings remain readable. Browser-data removal can erase notes; if saving fails, keep the tab open. External screen annotations are not captured.
