GATE CSE 2007: 85 single-choice MCQs, 150 marks.

Run ../start-quiz.command on macOS or ../start-quiz.cmd on Windows, then open http://127.0.0.1:8765/gate-cse-2007/ in the same browser/profile each time. Node.js is required; no npm packages or internet connection are needed. The macOS launcher opens a browser only with --with-browser. Direct file:// opening is unsupported.

This paper uses its original quarter-mark deduction: Q1-20 award 1 mark with -0.25 for an incorrect answer; Q21-85 award 2 marks, with -0.5 for incorrect ordinary questions and the first question of a linked pair. Linked pairs are 76/77, 78/79, 80/81, 82/83 and 84/85. A second linked answer is evaluated only when the first is correct and has no wrong-answer deduction. Unanswered questions score zero. Blank: 0/150; perfect: 150/150; all wrong: -35/150. No marks-to-all entries.

The supplied key is partial, not an official final key. This practice key fills its 36 blank entries by solving the questions. Supplied answers corrected after independent checks: Q24 to B, Q43 to C, Q48 to A, and Q51 to B. Q15 uses D as the practice interpretation counting successful comparisons; counting the final failed test exposes an ambiguity in the printed question. Full derivations, historical conventions and limitations are documented in KEY-NOTES.txt. The shared grammar for Q78/79 uses an original-exam crop restoring A -> bAA, which is misprinted as S -> bAA in the supplied reproduction.

The supplied CS-2007.pdf and Gate-2007-Cse-answer-key.pdf remain unchanged at their supplied locations and are not duplicated here. quiz-data.js records source filenames, SHA-256 hashes and crop provenance, including the supplemental original-exam reference. Original question images retain mathematics, figures, tables, code and all options. Resources needed to run the quiz are local.

Unfinished answers and Mark for review flags cache automatically in this browser. Clearing browser data or ending a private session can erase them. Clear response preserves its flag; Clear answers and fresh Attempt again clear flags. Flags do not affect scoring. If browser caching fails, keep the tab open.

Submit grades every question and saves only the latest attempt.json. A successful save clears the draft and flags; a failed save retains them and the report. Review last attempt rechecks saved responses without replacing the current draft; Back to quiz restores the prior view. Attempt again starts fresh practice and preserves the saved submission. Save report and Print report are available.

After Submit and in Review last attempt, the map uses green for Correct, red for Incorrect, and neutral for Unanswered. Linked answers that cannot be evaluated are amber; marks-to-all awards are blue. Marked questions show ★ instead of the usual status symbol, keeping their outcome color.

Submit saves review flags in attempt.json without changing scoring. A successful save clears draft/practice flags while keeping report stars; a failed save keeps the draft, flags, and report. Saved Review uses the submitted flags; Back to quiz restores the prior draft/view and its flags. Older submissions remain readable but cannot recover past review flags.

Timer presets are 180, 150, 120, 90, 60 or 30 minutes, default 180. Start, Pause and Reset control it. A running timer counts elapsed time while closed; zero never submits or locks the quiz. Submit resets it before validation. Clear answers preserves it. Reports and print hide timer controls. Theme is remembered separately.

Home-page Unsolved only filters papers. Reset saved attempts asks for confirmation and removes saved submissions while preserving unfinished browser drafts and theme. Never use that reset for development tests.

Verification: independent 85-entry key; all 340 choices and 45 linked combinations; 97 crops visually and pixel-checked; blank/perfect/mixed/negative scores; reports/maps; draft/review/flag/storage behavior; temporary-server score validation. Runtime and timer checks passed across all seven quizzes. HTTP and narrow in-app browser checks passed with no broken images, overflow or console errors. No real attempt was created or reset; supplied sources and existing attempts are unchanged. Native browser shutdown/reopen was not automated.
