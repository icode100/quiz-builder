GATE CSE 2025 - Set 2 (CS2, session 2)

Run start-quiz.command on macOS or start-quiz.cmd on Windows from the workspace.
Open http://127.0.0.1:8765/gate-cse-2025-set-2/ in the same browser/profile.
On macOS, --with-browser also opens the quiz list; the default starts only the server.

65 questions, 100 marks: 32 MCQ, 18 MSQ and 15 NAT.
Original numbering is GA 1-10 followed by CS 11-65. GA 1-5 and CS 11-35 carry
one mark; the remaining questions carry two. Incorrect MCQs deduct exactly
one-third of their marks. MSQ requires the exact set, without partial credit.
MSQ/NAT have no negative marking. Unanswered questions receive zero.
Blank: 0/100; perfect: 100/100; all wrong: -43/3 marks out of 100.
Marking reference: https://gate2025.iitr.ac.in/question-paper-pattern.html

The supplied key identifies CS2/session 2. CS 28 (D), 45 (A), 47 (D), and 53 (B)
remain MSQ even though each has one correct option. CS 56 accepts 260.20-261.20
and CS 65 accepts 0.70-0.80, inclusive. All other NAT keys are exact values.
There are no alternate keys, marks-to-all entries or linked dependencies.

65 lossless 240 DPI crops preserve every question, option, diagram, equation,
table, code block and original watermark. All source pages and final crops were
visually checked, and each crop matches a fresh source render pixel-for-pixel.
quiz-data.js records hashes, source pages, rectangles and pixel geometry.
Light mode and print use original colors; dark mode inverts images through CSS.
Click a question image for its unchanged full-resolution version.

The shared template supplies the question carousel/map, review flags, manual
Out of syllabus exclusions, six-preset timer, light/dark theme, browser drafts,
Submit report, Save/Print, saved Review and per-question rough-work notebook.
The server supplies the shared calculator. Exclusions preserve responses and
reduce eligible marks. Percentage is shown first; all-excluded is unavailable
with 0/0 marks. Score examples above assume no exclusions.

Unfinished answers, flags, exclusions, timer and last practice question restore
in this browser/profile. Submit saves the latest attempt.json and clears the
draft only after a successful save. Review and Retry preserve the saved file.
Rough-work ink and paper choices save separately per question and survive
Submit, Clear answers, Retry and Review. Browser-data removal can erase drafts
and notes. No real attempt is created or reset during construction or testing.
