GATE CSE 2011 - Code A: 65 MCQs, 100 marks.
Original order and numbering: CS 1-55, then GA 56-65.

Start ../start-quiz.cmd (Windows) or ../start-quiz.command (macOS), then open:
http://127.0.0.1:8765/gate-cse-2011/
Node.js is required; no npm packages, build step or internet are needed.

The supplied GATE2011.pdf is booklet Code A. Only Code A in Key2011.pdf is
used; the other booklet columns do not apply. Both originals remain unchanged
in Downloads, without PDF copies here. Data records filenames, SHA-256 hashes,
source pages, page dimensions, crop rectangles and marking provenance.
All 17 paper pages and both key pages were checked. The printed 20-page
denominator includes rough-work pages; the scan contains all 65 questions.

CS 1-25 and GA 56-60 carry one mark; the rest carry two. Wrong answers lose
exactly one-third of their marks, except linked second questions 53 and 55.
CS-53 requires CS-52 correct; CS-55 requires CS-54 correct. These dependents
have no wrong-answer deduction and are not evaluated when the prerequisite
is wrong or unanswered. Common-data pairs 48/49 and 50/51 are independent.
Blank: 0/100; perfect: 100/100; all wrong: -32/100.

All diagrams, mathematics, code, tables and options remain original. There
are 69 lossless 240 DPI crops and 73 displayed parts; shared contexts repeat
with both members. Minor skewed scan header fragments are retained wherever
trimming would risk question text. Images follow the theme and print light.

The carousel, map, review flags, timer, Home and shared Calculator are included.
Unfinished answers cache in the same browser/profile and HTTP origin. Submit
saves the latest attempt.json and clears the draft only after a successful
save. Review last attempt preserves current practice. See ../README.md for
the complete controls, cache and report behavior.

Verification: node tests/quiz-2011.test.cjs
Tests use the independent supplied-key fixture, simulated browser state and
disposable server folders. Never create/reset real attempts during testing.
